## 📱 Реализованный функционал (UI / UX)

### 1. **Onboarding Screen (`OnboardingScreen.js`)**

* Интерактивный слайдер возможностей приложения с индикацией (пагинацией).
* Плавный переход с сохранением просмотренных шагов.
* Быстрый переход к экрану регистрации/авторизации.

### 2. **Authentication Screen (`LoginScreen.js`)**

* **Переключение режимов:** Вход («Кіру») и Регистрация («Тіркелу») на одном экране.
* **Валидация полей:** Проверка пустых значений через `handleSubmit` с информативными уведомлениями (`Alert`).
* **Безопасность:** Переключение видимости пароля (глазок) с помощью `useState(showPassword)`.
* **Восстановление пароля:** Модальное окно (`<Modal>`) с функцией `handlePasswordReset` для отправки ссылки сброса на email.
* **Социальные сети:** Готовые кнопки для авторизации через Google и Apple.

## 🚀 Запуск проекта локально

### **1. Установка зависимостей**

```bash
npm install

```

### **2. Запуск Expo CLI**

Если при сборке возникают проблемы с памятью Node.js:

```bash
# Windows (PowerShell)
$env:NODE_OPTIONS="--max-old-space-size=4096"
npx expo start

# macOS / Linux
NODE_OPTIONS="--max-old-space-size=4096" npx expo start

```
